# DesignCraft Social Media Design Engine

## 1. Core Purpose
Interpret client briefs and reference benchmarks to produce high-impact, professional social media advertising graphics suitable for real client publishing, billboards, and social ad campaigns.

---

## 2. Graphic Design vs. UI Anti-Patterns (STRICT MANDATE)

### ❌ BANNED UI ANTI-PATTERNS
- **No Floating UI Badges / App Cards:** Never place logos or headlines inside floating rounded cards with glowing borders or drop-shadows that look like web modals.
- **No Candy Pill Buttons:** Never use `border-radius: 50px` candy pill buttons with thick borders.
- **No Website Footer Bars:** Do not create footers that resemble website bottom navbars with artificial chunky borders.
- **No Dashboard / Grid Cards:** Avoid dividing content into repetitive SaaS dashboard widget boxes.

### ✅ REQUIRED GRAPHIC DESIGN PRINCIPLES
- **Editorial Hierarchy:** Use bold, contrast-rich typography placed directly onto the visual canvas.
- **Seamless Brand Lockups:** Logos should sit directly on the background or integrate organically with existing background shapes/gradients.
- **Hairline Indicators & Vector Accents:** Use thin (1–2px) clean indicator lines, anchor dots (`●`), sharp triangular arrows, or subtle typographic bullets (`✦`, `◆`).
- **Unified Color Harmony:** Keep backgrounds cohesive (e.g., deep clinical navy `#001824`, rich warm amber, clean medical teal) without jarring artificial overlay blocks.
